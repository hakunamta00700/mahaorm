# Code of conduct

nimorm welcomes people who want to improve the library, documentation, tests,
and examples.

## Expected behavior

- Discuss the code and its user impact, not a contributor's identity or skill.
- Give specific, actionable review feedback.
- Assume mistakes are fixable and accept good-faith corrections.
- Respect privacy. Never publish another person's private information.
- Keep issue and pull-request discussions relevant to the project.

## Unacceptable behavior

Harassment, discrimination, threats, sexualized attention, personal attacks,
doxxing, and sustained disruption are not accepted in project spaces.

## Enforcement

Report conduct concerns privately through the repository's
[Security page](https://github.com/hakunamta00700/mahaorm/security) when private
reporting is available. If it is unavailable, request private maintainer contact
without posting sensitive details.

Maintainers may edit or remove comments, close or lock discussions, reject
contributions, or temporarily or permanently restrict participation. They will
consider context, impact, and repeated behavior and will avoid publishing a
reporter's identity without permission.
