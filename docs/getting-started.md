# Getting started

Start with the path that matches what you need:

1. [Install nimorm](installation.md) and verify the toolchain.
2. Finish the [5-minute quickstart](quickstart.md) to create and query one
   SQLite table.
3. Follow the [blog tutorial](tutorial.md) for validation, relations, updates,
   and typed queries in one program.

After the tutorial, use [models](models.md), [fields](fields.md),
[queries](queries.md), and [relations](relations.md) as focused guides. Move to
[migrations](migrations.md) before preserving production data.
